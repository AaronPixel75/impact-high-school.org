# How to Enable the Google Gemini API

If you are seeing an error, it is likely because the **Generative Language API** is not enabled for your project.

### Step 1: Go to the Console
Click this link to go directly to the API library in Google Cloud:
👉 **[Google Cloud Console - Generative Language API](https://console.cloud.google.com/apis/library/generativelanguage.googleapis.com)**

### Step 2: Select Your Project
1.  Look at the top blue bar.
2.  Make sure the project selected is the same one where you created your API Key (`AIza...`).

### Step 3: Click "Enable"
1.  You should see a big blue button that says **"ENABLE"**.
2.  Click it.
3.  Wait a few seconds for it to process.

### Step 4: Retest
1.  Go back to your website tab (`learning-hub.html`).
2.  Refresh the page.
3.  Try strictly chatting with the AI again.
